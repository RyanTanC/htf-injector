# HTF Injector — 你的「How to Fish」游戏作弊指南

你以为游戏作弊只是开挂？其实，它是一门艺术。  
这是一把为「How to Fish」游戏量身打造的注入器，让你轻松掌控队友操作、批量控制、物理恶搞——甚至，还能在海上漂浮时精准传送到好友身边。

## 功能亮点

**第一，玩家列表**  
就像你手机里的通讯录，但这里显示的是队友的血量、位置、距离、持有物和 SteamID。刷新一下，所有信息尽在掌握。

**第二，单体操作**  
想传送到队友身边？一键搞定。想拉他到你面前？也没问题。治疗、杀死、点燃、中毒、复活——这些操作，就像你点外卖一样简单。

**第三，批量操作**  
全队治疗、全队传送、全队掉落、全队杀死——甚至还能给全队物资和金钱。但说实话，金钱功能目前不可用，因为 MoneyManager 只支持本地玩家。

**第四，限制控制**  
锁定禁动、禁止购买、禁止拾取、禁止跳跃、禁止攻击——这些限制，就像给队友套上了一层“紧箍咒”。

**第五，物理恶搞**  
吸队友、吸全队、高空抛投、旋转、缩小、放大、倒吊、弹球——这些恶搞功能，让你的游戏体验充满欢乐。

**第六，房间管理**  
复制房间信息、踢人、封禁、切换昼夜/天气——但有些功能是实验性的，可能无效。

**第七，运行日志**  
滚动显示、分类过滤、复制全部、清空——所有操作记录，一目了然。

## 安装与使用

1. **下载**：从本仓库下载最新版本。
2. **注入**：双击 `双击注入.bat`，等待注入完成。
3. **启动游戏**：进入「How to Fish」游戏。
4. **打开菜单**：按 F9 键打开作弊菜单。
5. **切换页签**：切到「队友」页签，开始你的操作。

## 注意事项

- **主机权限**：修改他人状态的操作需要主机权限；非主机时按钮置灰。
- **反射兜底**：禁止购买/拾取/跳跃/攻击补丁使用动态方法名解析；目标缺失时该功能跳过。
- **给金钱**：MoneyManager 仅暴露本地玩家通道，无法给指定玩家/全队真实到账；按钮已标注“不可用”。
- **房间密码/最大人数/昼夜天气/封禁**：FishNet 房间相关 API 未在源码中直接暴露，当前为实验性占位，实际游戏中可能无效。
- **玩家 ESP**：最多显示 16 个最近玩家，超出不画。
- **吸人/锁定/旋转等每帧恶搞**：仅在主机端执行（非主机静默跳过），节流 0.15s，位置类走 Server.TeleportPlayer 合法通道，避免 Steam 发送限流。
