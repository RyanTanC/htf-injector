### 第三轮：拖滑块闪烁（IMGUI 跨事件状态污染 —— 最隐蔽的坑）
**现象**：拖动滑条整个菜单疯狂闪烁。
**根因**：IMGUI 一帧**多次**调用 `OnGUI`（MouseDrag / Layout / Repaint 各一次）。
`GUILayoutUtility.GetLastRect()` 在 **Layout 阶段返回布局计算的中间值**，**Repaint 阶段才是最终值**。
测量不区分事件 → `_viewTop`/`_contentH`/`_scrollH` 一帧内被写多次、在两个值间跳 → 自适应高度每帧抖。
拖滑条额外产生 MouseDrag 事件，把这个差异彻底放大暴露。
**正解（IMGUI 铁律）**：所有 `GUILayoutUtility.GetLastRect()` 测量 + 状态写入**只在 `EventType.Repaint` 做**，
Layout/MouseDrag 一律沿用缓存的稳定值。同理：
- `AutoScroll()` 写 `_scroll.y`，而 `_scroll` 是 `BeginScrollView` 的布局输入
  → Layout 阶段改它 = 边算布局边改布局输入，内容上下抖。只在 Repaint 调用。
- 生成页 `_contentH`/`_scrollH`/`_spawnOtherH`/`_spawnListH` 同样只在 Repaint 重算
  （列表高喂回 `_spawnOtherH` → 窗口高，跨阶段重算会互相追着变，是闪烁的第二条回路）。
- `OnGUI` 的高度自适应也只在 Repaint 执行（DrawWindow 刚更新完测量，顺序最自洽）。
- 已删除废弃的 `_belowH` 实测字段，统一用固定 `_belowBudget`。

  `PlayerCamera.LookInput` 是 `{ get; private set; }`，外部赋值编译不过，要用 `Traverse.Create(...).Property("LookInput").SetValue(...)`。
- ResetAll 里 `_moveWhilePanelOpen = false`。
