## 2026-09-01 IMGUI 错误框计数崩溃修复（实弹反馈）

用户实弹报 `Getting control 10/12/13's position in a group with only 10/12/13 controls` + Steam App List SSL 错误。
- 根因：错误框数量 `_errN` 在 Repaint 由 UpdateBelowBudget 更新，但 DrawErrorBox 在 Layout/Repaint 两阶段都绘制 → 错误入队瞬间两阶段控件数差 1，逐条崩一次（数字递增 = 队列逐条变长）。
- 修复：新增 `UpdateErrorSnapshot()` 只在 **Layout** 冻结错误快照（数量/文本/高度/按钮文案 `_errCount`），DrawWindow 在 ApplyFontScale 后调用；UpdateBelowBudget 只累加冻结的 `_errBoxH` 不再碰队列。
- 铁律补充：IMGUI 里"测量（尺寸）在 Repaint 做、控件数量/内容在 Layout 冻结"——已写回 skill。
- SSL 错误本身是 Steam 连接问题（本地网络/Steam 状态），非 UI 缺陷；错误框正常显示它。
- 编译 0 错误，payload 151040 字节已同步。
